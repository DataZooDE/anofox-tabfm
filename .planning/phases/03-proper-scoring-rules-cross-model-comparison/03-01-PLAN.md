## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Denial of Service | CRPSUpdate STRUCT read | medium | mitigate | Bounds-check `K==0 || border_vals.size()!=K+1` and `dist_val.IsNull()`/child NULL before indexing — skip row; never OOB-index a malformed distribution |
| T-03-02 | Denial of Service | ComputeCRPS per-bin integral | medium | mitigate | Guard `wi <= 0.0` (skip degenerate/zero-width bin, accumulate cum) — no divide-by-zero in Case C density |
| T-03-03 | Tampering | PSR-04 bind-gate | low | mitigate | 2-arg DOUBLE overload throws at bind — point estimates cannot silently produce a meaningless score |
| T-03-SC | Tampering | npm/pip/cargo installs | n/a | accept | No new packages introduced (RESEARCH Package Legitimacy Audit: none); tools/parity uses existing uv project deps only |

No high-severity residuals: the surface is a pure-math aggregate over columns with all indexing bounds-checked.
